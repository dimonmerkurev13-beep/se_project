### Итоговый проект  

**Задание для самостоятельного исполнения:**  

1) сделать файл `./json/data.json` со своими данными, примерно 10-20 пунктов - рейтинг игр, книг, мест отдыха, велосипедов, аниме, кино и т.п. (на ваш выбор), **название** в таблице поменять на своё и сделать в таблице **первую строку с заголовками** под ваши данные  

   - сейчас в таблице три значимые колонки для отображения (Фамилия, Имя, Рейтинг), в вашей реализации должно быть НЕ МЕНЬШЕ (можно больше)  

2) сделать `своё стилевое оформление` (таблиц, кнопок, шрифтов, размещения) - внести изменения в файл `style.css`  

3) добавить на форму html-страницы `числовое поле ввода` (с прокруткой вверх-вниз) - для установки лимита рейтинга, начиная с которого и выше значения выводятся зелёным, иначе - красным (сейчас в программе установлено 190 по умолчанию, надо сделать так, чтобы пользователь мог это менять)  

4) добавить `возможность для удаления пользователя`  

   - как это оформить:  
     - либо добавить дополнительную кнопочку `DEL` - как сейчас есть кнопочка `EDIT` для редактирования данных пользователя,  
     - либо сделать каждую строку таблицы кликабельной - когда нажимаешь на строку, то переходишь к просмотру пользователя на новой странице и там есть кнопки `Сохранить` и `Удалить`, тогда уже кнопка `EDIT` не нужно (её убрать)  

---
